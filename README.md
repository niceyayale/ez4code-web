# EZ4Code - Privacy-First Developer Tools Platform

> 一站式编程工具与代码学习平台 | One-stop programming tools and code learning platform

**EZ4Code** (易知码) is a free developer platform that runs entirely in your browser. No accounts, no tracking, no data collection — all tools execute locally on your device.

## Features

- **296+ browser-based tools** — UUID, JWT, JSON, Base64, AES, and more
- **Privacy-first** — No registration, no tracking, no data upload
- **Multi-language** — 9-language i18n (en/zh/ja/es/fr/de/pt/ko/ru)
- Developer guides — In-depth articles on UUID, JWT, JSON, Base64
- Cheatsheets — Quick reference for 25+ programming languages
